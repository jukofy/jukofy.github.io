# jukofy.github.io
Tagline: All your downloads — files, video and torrents — in one app. Fast, clear, and in your language.  Short: Jukofy Downloader is a desktop download manager that brings files, video, playlists and torrents into one app — with audio extraction, trimming, subtitles, eight languages and a native right-to-left interface. Free, with no paid tiers.
